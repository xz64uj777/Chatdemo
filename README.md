# BuildWorks — Field Ops

A mobile-first construction-site game prototype. Open `index.html` in a modern browser; no build tools or install are required.

## Current playable loop
- Drive a wheel loader around the site with on-screen controls or WASD / arrow keys.
- Buy gravel from Materials.
- Lower the loader bucket, drive close to the gravel stockpile, and scoop.
- Deliver the load inside the highlighted pad or haul-road zone.
- Finish contracts to earn cash and reputation.
- Cycle between a wheel loader, articulated dump truck, and excavator; the trench job requires the excavator.

## Controls
- **Arrow buttons / WASD / arrow keys:** drive
- **Lower/Raise bucket:** prepare the loader for scooping
- **Scoop:** load gravel near the stockpile
- **Dump load:** deliver material in the highlighted zone
- **Work:** context action for the active contract
- **Machine:** cycle equipment
- **Materials / Contracts:** open shop and work-order panels

## Prototype status
This is an early playable prototype, not a finished simulator. Priorities for the next iterations are equipment-specific handling, visible loading and dumping animations, truck loading/hauling, more contracts, persistent progress, and real-device testing.
